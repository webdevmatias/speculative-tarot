# Imagens das Cartas do Tarot Especulativo

Coloque os arquivos de imagem das cartas nesta pasta (`public/assets/cartas/`).

No Next.js, qualquer arquivo colocado em `public/assets/cartas/` pode ser acessado diretamente pela aplicação via `/assets/cartas/[nome-do-arquivo]`.

## Proporção recomendada
- **Proporção:** 2:3 ou 3:4 (tamanho recomendado: aprox. `600 x 900 px` ou `800 x 1200 px`).
- **Formatos suportados:** PNG, JPG, WEBP, SVG.
